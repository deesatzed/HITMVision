# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is
A software-engineering agent cockpit for Apple Vision Pro with a human in the middle (HITM). Agents do the work; the human is interrupted only when a decision matters, judged by a safety floor plus a small gate model and the project's risk profile. It is built first, then used to build Diagnostic Theater (a separate project, not in this repo). This repo was split out of `/Volumes/WS4TB/DM_FEET/VisOsDx` on 2026-10-27 with history kept; the old copies there are not maintained.

Start with `docs/plans/`: the 2026-10-25 design and Phase 2 plan, the 2026-10-26 decision-card and rules design (decisions R1–R11, E1–E9), and the current piece plan. `HITMCockpit/BUILD_NOTES.md` is the running log of commands, counts and live measurements.

## Layout
- `HITMCockpit/` Swift package: `HITMCore` (headless: event log, floor gate, OpenRouter gate client, planner, classifier, shared mind in `.hitm/`), `CockpitUI` (shared SwiftUI store, sample data, panels), `CockpitPrototype` (Mac app), `GateLiveCheck` and `PlannerLiveCheck` (manual live tools).
- `HITMVision/` visionOS app generated by `xcodegen` from `project.yml` (flat window plus a bounded volume).

## Commands (verified 2026-10-27)
- Tests: `cd HITMCockpit && swift test` (HITMCoreTests 283, CockpitUITests 34).
- visionOS build: `cd HITMVision && xcodebuild -project HITMCockpitVision.xcodeproj -scheme HITMCockpitVision -destination 'generic/platform=visionOS Simulator' build`
- Regenerate the Xcode project: `cd HITMVision && xcodegen generate --spec project.yml`

## Rules for working here
- The safety floor always wins: a gate answer can only add a human check. Never read profile fields to judge strictness; use `FloorGate.evaluate`. Load profiles only through `RiskProfile.decodeOrStrict`.
- Sample data is labeled PROTOTYPE SAMPLE DATA and stays on the open-items list until replaced by real behavior.
- `OPENROUTER_API_KEY` lives in a git-ignored `.env` (present in this repo's root, ignored by git). Never open, print, log or commit it. Live checks send invented samples only unless the owner approves a destination.
- Models are chosen by the owner; look up IDs, do not use remembered ones. Current choices: gate `anthropic/claude-haiku-5.5`, default worker `deepseek/deepseek-v4.1-flash-1017`.
- Stage named files only when committing.
